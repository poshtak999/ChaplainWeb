# Chaplain+ 🇺🇦

Платформа для капеланів України - веб-додаток для надання духовної підтримки військовим.

## 🚀 Особливості

- **Біблійна підтримка** - колекція біблійних віршів для натхнення
- **Молитовна підтримка** - молитовник для різних ситуацій
- **ПТСР підтримка** - матеріали з роботи з посттравматичним стресовим розладом
- **База даних SQLite** - зберігання всіх постів у базі даних
- **REST API** - повний набір endpoints для управління контентом

## 📋 Вимоги

- Node.js 18+
- npm або yarn

## 📝 Технології

- **Frontend:** React 19, Vite, Tailwind CSS, React Router
- **Backend:** Express.js, SQLite (better-sqlite3)
- **База даних:** SQLite
